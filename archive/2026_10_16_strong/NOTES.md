# 强视图对齐（Noisy Student）第 1 轮：Ar→Cl（2026-10-16）

## 概要

**为什么做**
簇级命名诊断（`../2026_10_16_diag_cluster/`）发现：学生的表示没有被 CLIP 同化（K=520 簇纯度 82.5%），
但分类器被同化了（和 CLIP 一致率 94%）。原方法中学生和老师看同样干净的图像，最优解就是复制老师。
Noisy Student 的思路：让学生在强增强视图上匹配老师的判断，逼它依赖自己的表示。

**做了什么**
`main.py` 新增 `--align_view weak|strong|both`（默认 weak = 原方法）：strong 时学生在 `strong_img`（mocov2 强增强）上
计算对齐损失，老师的计划不变；both 时弱 / 强视图的对齐损失各占一半。
`bash scripts/run_strong.sh`：Ar→Cl × {ot_strong, ot_knn10_strong, ot_knn10_both}，完整 40 epoch，seed 42。

**结论**（最后 5 次评估均值，%）

| 组 | 准确率 | 相对 ot | 相对 ot_knn10 | 峰值 → 最终 |
|---|---|---|---|---|
| ot | 74.39 | | | 74.85 → 74.48 |
| ot_knn10（底座） | 75.19 | +0.81 | | 75.56 → 75.28 |
| **ot_knn10_both** | **75.98** | **+1.59** | **+0.79** | 76.04 → 76.06 |
| ot_knn10_strong | 74.78 | +0.40 | −0.41 | |
| ot_strong | 73.82 | −0.57 | | |
| COSMO（公开最好） | 76.4 | | | |

- both 在底座上再涨 0.79 个百分点，离 COSMO 只差 0.4。
- both 第一次保住了峰值：第 748 步 76.04，最终 76.06；ot 和 ot_knn10 都会从峰值回落。
- 只用强视图（strong）反而更差：弱视图提供稳定的对齐信号，强视图逼学生不照抄老师，两者都需要。

**证明了什么**
- 训练学生的方式（输入和老师不同）能把底座再往上推，而且解决了「先快后退」，与「分类器被同化」的诊断一致。

**第 2 轮（`results_r2/`）：在 Pr→Cl、Re→Cl 上验证 both**

| 任务 | ot | clip_soft | ot_knn10 | **ot_knn10_both** | 相对 ot_knn10 | 相对 ot | COSMO |
|---|---|---|---|---|---|---|---|
| Ar→Cl | 74.39 | 73.28 | 75.19 | **75.98** | +0.79 | +1.59 | 76.4 |

- both 在三个任务上都成立，相对底座 +0.8 ~ +1.6，相对原方法 ot +1.6 ~ +2.1；也都超过了 clip_soft。
- 和 COSMO 比：Pr→Cl、Re→Cl 已超过，Ar→Cl 还差 0.4；三个任务平均 76.07 对 76.0，基本持平、略高。

**没有证明的**
- 1 个种子；需要补种子（论文报告 3 个种子平均）。
- 没有测不带近邻平滑的 ot_both（可选，论文消融用）。
- 弱 / 强的权重比（现在各 0.5）没有调。
