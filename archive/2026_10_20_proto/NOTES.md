# 类原型修正（离线，不训练）（2026-10-20，`scripts/run_proto.sh`）

## 概要

**为什么做**
H1（`2026_10_20_h1`）：学生缺口继承自老师的固定文本原型分类头（老师「探针 − 实际」与学生几乎一一对应）。
检验：不用标签地移动文本原型，能拿回多少。

**做了什么**
H1 的快照（12 个任务 p000 + 4 个 cap02 p100），CLIP 图像特征上从文本原型出发迭代：分配（soft / hard / Sinkhorn 均匀 / Sinkhorn √计数）→
原型 = 分配加权的图像均值（λ = 0）或与文本原型各半（λ = 0.5），可选中心化；报告第 1 / 3 / 10 轮。学生瓶颈特征上同样做一遍。

**结论**（相对老师，百分点；同一目标域的三个任务 CLIP 侧结果相同）

| | Clipart | Art | Product | Real World |
|---|---|---|---|---|
| p000 老师（零样本） / 探针 | 63.64 / 81.47 | 77.75 / 82.90 | 87.07 / 95.34 | 87.72 / 90.61 |
| p000 hard λ0.5 第 1 / 3 / 10 轮 | +3.4 / +2.2 / +0.9 | +2.0 / 0.0 / −1.5 | +2.5 / +2.5 / +2.2 | +1.2 / +0.7 / +0.4 |
| p000 λ0（只用图像均值）第 10 轮 | −8 ~ −14 | −12 ~ −29 | −1 ~ −10 | −5 ~ −11 |
| p100 最好（hard λ0.5）第 10 轮 | - | −0.16 / −0.70 | −0.09 | −0.48 |
| p100 学生特征最好 | - | −0.54 / −0.87 | −0.47 | −0.53 |

1. **训练后的模型上完全无效**：p100 所有设置 ≤ 0（老师侧和学生侧都是）。这是第 5 个失败的「训练后无标签读取」
  （近邻平滑、重拟合分类头、类边际重分配、簇命名、原型修正）。探针缺口用无标签方式拿不到。
2. **训练前一步修正有效但被训练覆盖**：p000 第 1 轮四个目标域都 +1.2 ~ +3.4，但训练本身已远超（Clipart 63.6 → 77），
   而且继续迭代会漂移（自我确认）；Product 例外，稳定 +2.2。
3. **CLIP 图像空间里类不是紧凑的簇**：只用图像均值的原型比文本原型差得多（λ0 全面大幅为负）。线性探针 95 的可分性来自判别方向，
   不是簇结构，所以「按自己的分配算类中心」到不了探针。
4. Sinkhorn 均匀边际在 Art 上最差（p000 −9.5 / p100 −7.9），与 Art 最不均衡一致。

**证明了什么**
- 「老师分类头是固定文本原型」虽是缺口来源，但离线的无标签原型修正修不了它；训练后的特征上没有可读出的额外信息。
- 有效的改动都来自训练过程本身（cap02、tstrong、clswsqrt），后续应在训练中改，而不是事后读取。

**没有证明的**
- 训练中可学习的原型是否有用（改变的是训练动态：adapter 不必去贴合固定原型），离线检验回答不了。
