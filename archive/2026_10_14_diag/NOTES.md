# 实验 0：OT 静态诊断（2026-10-14）

## 概要

**为什么做**
VSFOT 的核心是用 CLIP 构造代价 Cv，逐批做 Sinkhorn，得到计划 gamma1，再用它去对齐模型。
我们怀疑这一步可能有三个问题，想在花大量时间改方法之前，先不训练、直接测一下这些问题是否真实存在：
- H1：每批只有 64 张图，很多类不在批内，Sinkhorn 可能把质量分给这些缺席类，引入噪声；
- H2：计划可能对 CLIP 的 logit 尺度（代码写死 100）和 ε（0.2）很敏感，结果不稳定；
- H3：计划是在 Cv 下求的，却在模型代价 Cm 下计算损失，两者的最优解之间可能存在实质差距。

**做了什么**
对 Ar→Cl（难）和 Pr→Re（易）两个任务，正常训练到 1/2，在训练进度 0、1/4、1/2 处保存快照
（模型、CLIP adapter、记忆库）。然后对每个快照，按训练时的方式逐批构造计划，不更新任何参数，
测量缺席类质量、改尺度和 ε 后计划准确率的变化，以及 Cv 计划与 Cm 精确最优的代价比。

**结论**
- H1：缺席类质量为 7–21%，高于 5%，按判据假设成立；但这部分质量和 μ_p 在缺席类上的质量完全相等，
  是由 μ_p 预先决定的，和 Sinkhorn 的分配无关。
- H2：只在尺度变小时敏感（100 → 50 下降 4–6.5 个百分点），本质上是 μ_p 随尺度变化；固定 μ_p 后不敏感，对 ε 也不敏感。
- H3：早期缺口明显（1.35–1.54），后期接近 1；但本轮后期的数值有计算偏差，以快速诊断的修正结果为准。

**证明了什么**
- 当前 OT 计划的 argmax 基本就是 CLIP 的 argmax，任何阶段都没有超过 CLIP。
- 训练中模型准确率被拉到 CLIP 的水平后就停住了，OT 这一步没有带来超出 CLIP 的信息。
- 三个指标都主要由 μ_p 和 CLIP 的尖锐程度决定。

**没有证明的**
- 还不能说明 OT 机制本身是否有用（见快速诊断的 μ_p 消融）；
- 这是静态测量，不能代替完整训练的消融实验。

## 判据

- H1：缺席类拿到的质量 < 5% → 假设 1 弱
- H2：尺度 / ε 翻倍范围内，计划 argmax 与真标签一致度变化 < 1 个百分点 → 假设 2 弱
- H3：Cv 方案在 Cm 下的代价 / Cm 精确最优代价 < 1.1 → 理论缺口无实质

## 准确率（%）

| | Ar→Cl p000 / p025 / p050 | Pr→Re p000 / p025 / p050 |
|---|---|---|
| CLIP | 57.7 / 66.1 / 66.6 | 79.1 / 82.0 / 82.2 |
| 计划 argmax（实际 μ_p） | 56.2 / 65.1 / 66.4 | 78.3 / 82.0 / 82.2 |
| 计划 argmax（均匀 μ_p） | 42.9 / 46.1 / 47.3 | 52.4 / 54.1 / 55.5 |
| 模型 | 41.9 / 65.9 / 67.1 | 75.7 / 82.2 / 82.2 |

训练曲线：Ar→Cl 从约 600 步起停在 67–68%；Pr→Re 从约 400 步起停在 82%。

## H1：缺席类质量 —— 按判据「不弱」，但来源是 μ_p

- 缺席质量逐批中位数：Ar→Cl 21% → 15%，Pr→Re 11% → 7%，全部 > 5%。
- 和「μ_p 在缺席类上的质量」逐批相差 < 1e-7：Sinkhorn 收敛后行边际被强制等于 μ_p，这部分质量由 μ_p 预先决定。
- 按 1/类频率重加权：缺席质量只增加 0–1.2 个百分点，argmax 几乎不变。
- 均匀 μ_p：缺席质量约 39%，计划准确率下降 14–27 个百分点。

## H2：尺度敏感 —— 只在一个方向敏感，且通过 μ_p 起作用

joint 模式（clipProb 和 μ_p 同时换尺度），ε = 0.2：

| 尺度 | 50 | 100 | 200 | CLIP argmax |
|---|---|---|---|---|
| Ar→Cl p000 | 52.0 | 56.2 | 57.4 | 57.7 |
| Pr→Re p000 | 71.8 | 78.3 | 79.0 | 79.1 |

- 翻倍范围最大变化 4.2 / 6.5 个百分点，几乎全来自 100 → 50；100 → 200 只有 0.1–1.2 个百分点。
- prob_only 模式（μ_p 固定）：变化 < 1 个百分点；ε 翻倍：< 0.6 个百分点。
- 尺度越大，计划越接近硬 CLIP 标签（有效类数 3.2 → 1.6），从下方逼近 CLIP argmax，从不超过。
- 随训练推进，敏感度下降（Ar→Cl 4.2 → 1.4，Pr→Re 6.5 → 0.65）。

## H3：理论缺口 —— 本轮 p025 / p050 的数值有偏差，已在快速诊断中修正

| Cv / Cm 精确最优 | p000 | p025 | p050 |
|---|---|---|---|
| Ar→Cl | 1.54 | 1.18 | 1.08 |
| Pr→Re | 1.35 | 1.07 | 1.01 |

问题：Pr→Re p050 有 67 批的比值 < 1，Cm 熵解在后期也 < 1，这是不可能的。
原因：POT 的 Sinkhorn 每轮最后更新行，行边际精确（≈ 5e-8），列边际未收敛时 L1 误差 0.2–0.3%；
代价矩阵有 −log(p+1e-6) 项（最大约 14），后期最优代价只有 0.3–0.5，微小的质量偏差就能让代价下降几个百分点。
列误差与比值的相关系数为 −0.14 ~ −0.45，和这个解释一致。修正后的结果见 `../2026_10_14_diag_quick/NOTES.md`。
