## 论点 1：未经任何目标域适配的源模型，其特征结构已经能纠正 CLIP 的伪标签

**论点**
只在源域训练过、从未在目标域上更新过的源模型，单看自己的预测很差（Ar→Cl 47.5%），
但把它的**特征空间结构**用来平滑 CLIP 的伪标签，就能稳定超过 CLIP 本身。
CLIP 自己的特征空间做同样的操作反而更差。
所以 SFDA 中学生模型的价值不在于它的预测，而在于它对目标域数据结构的刻画，这是 VLM 提供不了的信息。

**证据**（`2026_10_16_diag_struct/`，p000 快照，全数据集 Ar→Cl N = 4365，Pr→Re N = 4357）

| | Ar→Cl | Pr→Re |
|---|---|---|
| CLIP argmax | 63.64 | 87.72 |
| 源模型 argmax | 47.51 | 74.25 |
| **学生（源模型）特征空间：(自身 + k 近邻) CLIP 概率平均，k = 10** | **66.96（+3.32）** | **89.33（+1.61）** |
| 同上，k = 5 / 20 | +3.14 / +3.34 | +1.35 / +1.88 |
| 纠正 / 改坏（相对 CLIP，k = 10） | 242 / 97 | 142 / 72 |
| 对照：CLIP 图像特征空间做同样的投票（k = 10） | 62.20（−1.44） | 84.39（−3.33） |
| 对照：只用近邻、不含自身（k = 10） | 58.85（−4.79） | 80.56（−7.16） |

（准确率 %，括号内为相对 CLIP 的百分点。）

**排除了哪些质疑**
- 「增益来自学生在目标域上学到的东西」：p000 快照保存在第一次 `model_optimizer.step()` 之前，学生就是原始源模型。
- 「增益其实是 CLIP 自己的结构」：在 CLIP 图像特征空间做完全相同的近邻投票，结果为负（−1.4 / −3.3）。
- 「只是挑出来的超参数」：k = 5 / 10 / 20 结果相差 < 0.5 个百分点，两个任务方向一致。
- 「用了标签」：方法本身不用任何目标域标签，标签只用于评估。
- 「改对少、改错多」：纠正样本数是改坏数的 2–2.5 倍。

**需要坦白的局限**
- 静态测量，不是训练结果；能否在训练中累积成最终准确率提升，待 `--knn_k` 完整训练验证。
- 用的是当前 CLIP 概率、BN eval 模式下的特征、全数据集一次性建近邻；训练中只能用记忆库和随训练更新的特征库。
- p000 的「CLIP」是插入了 adapter 的那份 CLIP 拷贝（main.py 的 `clipAdapter` 深拷贝原始 CLIP 后插入 adapter），
  adapter 刚初始化、尚未训练（xavier，gain 0.1，接近恒等），所以和纯零样本 CLIP 略有差别；记忆库则是用原始 CLIP 初始化的。
- 只测了两个任务（一难一易）、每个快照 1 次，没有多种子。
- 必须保留自身的 CLIP 概率：只用近邻会明显变差。论点是「结构 + 老师」的组合，而不是结构单独就够。

**相关数字（后续阶段，同一出处）**：knn_clip_s（k = 10）在 p025 / p050 仍为 Ar→Cl +2.15 / +1.15、Pr→Re +0.64 / +0.21，
6 个快照全部为正；CLIP 特征空间的对照全部为负。
