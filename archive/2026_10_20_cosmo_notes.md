# COSMO 方法与消融整理（2026-10-20，来源 https://arxiv.org/html/2608.04604）

## 结构
- 源模型 f_s 冻结（只用于初始锚点）；目标模型 f_t（ResNet-50，从源模型初始化）全部训练；CLIP 图像 / 文本编码器冻结，**只学提示上下文**
  （4 个共享 token，用 "a photo of a" 初始化，不学类别 token）。
- **没有师生互相监督**：两个分支都由同一个「共识」监督，共识从两个分支更新前的预测重新聚合，detach。
  - 专家权重 r = max(log K − H(p), ε)，归一化；共识 = 按熵加权的专家乘积 q ∝ ∏ p_m^{w_m}（中心化 logit 的加权和）
  - 初始锚点 c⁽⁰⁾ = {源模型, 初始 CLIP}，算一次缓存；动态共识 c⁽ˡ⁾ = {目标模型, 当前 CLIP}
  - CSM：每个 epoch 按共识熵的排名 u ∈ [−1, 1]，γ = 1 + 0.5·d(e)·u（d 从 1 线性衰减到 0），ĉ = c⁽⁰⁾ + γ(c⁽ˡ⁾ − c⁽⁰⁾)。
    低熵样本向锚点收缩、高熵样本远离锚点；最后一个 epoch 退化为动态共识
- 损失：L_v = IIC(p_v, q̃)（只更新提示）；L_t = 1.3·IIC(p_t, q̃) + 0.4·CE(p_t, argmax q̃) − 1.0·H(批平均 p_t)
- 优化：两个 SGD（Nesterov 0.9，wd 1e-3），η = η0(1 + 10j/J)^−0.75；Office-Home η0 = 5e-3，瓶颈 η0，骨干 / 分类器 / 提示 0.1η0；30 epoch

## 消融（Office-Home / DomainNet-126，ViT-B/32）
| 设置 | OH | DN |
|---|---|---|
| VLM → 目标（单向） | 81.2 | 80.3 |
| **VLM ↔ 目标（互相监督，= 我们的结构）** | **84.8** | **82.0** |
| 固定共识 | 82.6 | 80.8 |
| 共识 + 用当前目标模型重新聚合 | 85.4 | 83.4 |
| 两分支都重新聚合，无 CSM | 85.8 | 84.6 |
| COSMO（+ CSM） | 86.4 | 85.1 |

目标函数（OH）：完整 86.41；去 VLM 侧 IIC 85.04；去目标侧 IIC 84.32；**去硬 CE 79.66**；去 diversity 85.54；只有软对齐 77.91；只有硬 CE 84.92。
共识构造：PoE + 熵加权最好（86.4）；MoE 均匀 85.5；PoE 均匀 85.7。
机制：直接蒸馏 VLM 时「只有源模型对」的样本保留 42.8%、「只有 VLM 对」吸收 95.2%；COSMO 78.1% / 91.1%。
种子：Office-Home 86.410 ± 0.084（3 个种子），逐任务标准差平均 0.199，最大 C→A 0.370。
论文表中 VSFOT（公开数字）Office-Home 85.3、DomainNet-126 82.6、VisDA-C 90.6；COSMO 86.4 / 85.1 / 91.4。
