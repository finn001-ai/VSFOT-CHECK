# 训练停滞诊断：训练动态 + 共识塌缩（2026-10-17）

## 概要

**为什么做**
`ot` 和 `ot_knn10_both` 在第 748 步（第 11 个 epoch）之后准确率基本不动，后 70% 的训练没有贡献。
停滞是我们要解决的核心问题，要先弄清楚它是怎么发生的：是学习率 / 权重的问题，还是老师和学生收敛到了同一个不动点；
如果是后者，并集里丢掉的样本是学生吸收了老师的错误，还是老师吸收了学生的错误。

**做了什么**
1. 第 1 轮 `scripts/run_dynamics.sh`：`ot_dyn`、`ot_knn10_both_dyn`（Ar→Cl），`--log_dynamics` 每个 epoch 记录
   老师准确率、一致率、并集、翻转率、伪标签准确率、熵和各项损失。
2. 第 2 轮 `scripts/run_collapse.sh`：都以 `ot_knn10_both` 为底座、都加 `--log_samples`（逐样本预测），
   `tools/collapse_analysis.py` 统计 4 种状态（都对 / 只有学生对 / 只有老师对 / 都错）的转移：
   - `both_samples`：不干预（对照）
   - `both_freezeT020`：第 544 步后冻结老师
   - `both_adapter12`：12 个 block 都插 adapter（老师容量 ×4）
   - `both_selfknn025`：进度 0.25 后近邻平滑改用 (CLIP + 学生) / 2

一致性检查：`ot_dyn` = 74.39、`ot_knn10_both_dyn` = `both_samples` = 75.98，和不记录时逐点相同；
`freezeT020`、`selfknn025` 在触发点之前和底座逐点相同。记录本身不影响训练。

**结论**（Ar→Cl，seed 42，最后 5 次评估均值）

| 组 | 学生 | 最终老师 | 最终一致率 | 并集峰值 → 最终 | 丢失 / 救回 | 最终都错 |
|---|---|---|---|---|---|---|
| both_samples（底座） | 75.98 | 75.40 | 97.1 | 79.34 → 76.56 | 204 / 83 | 1023 |
| both_freezeT020 | 75.16 | 72.21 | 88.2 | 78.99 → 77.00 | 143 / 56 | 1004 |
| both_adapter12 | 74.83 | 74.46 | 98.0 | 77.00 → 75.17 | 180 / 100 | 1084 |
| both_selfknn025 | 75.82 | 75.28 | 96.9 | 79.34 → 76.43 | 213 / 86 | 1029 |

1. **停滞不是优化问题**：第 748 步学习率还有 82%；对齐权重第 1360 步才加满。是师生收敛到同一个不动点：
   伪标签从第 204 步起就不比学生好（第 748 步 73.4 / 74.9 对学生 76.0），一致率 86% → 97%，熵降到约 0.2。
2. **漏洞在学生侧：学生吸收老师的错误。** 底座从并集峰值（第 612 步）到最终丢失 204 个样本：
   峰值时「只有学生对」128 个（其中 94 个学生最终改成了老师当时的错误预测），「只有老师对」43 个（24 个老师改成了学生的错误），都对 33 个。
3. **两个方向的蒸馏，作用不同**（底座，峰值 → 最终）：
   - 老师 → 学生：「只有老师对」160 个中 110 个变成都对（学生学会），但「只有学生对」274 个中 128 个变成都错。
     冻结老师后同样是 102 个学会、143 个被带错。**后期这个方向是零和甚至净负的。**
   - 学生 → 老师：「只有学生对」274 个中 108 个变成都对（老师学会）。冻结老师后这部分没了，老师停在 72.2，
     学生也掉了 0.8。**这个方向是净正的，MGVA 不能停。**
4. **H1（老师容量不够）不成立**：12 个 adapter 让老师更快贴上学生（一致率 98%），并集峰值更早更低（第 476 步 77.0），
   丢失更多，学生 74.83（−1.15）。容量越大，塌缩越快。
5. **后期混入学生概率（selfknn，w = 0.5）没有作用**：75.82，丢失 213，和底座相同。目标「平均」进去的学生判断，
   在共识样本上和老师一样，在分歧样本上被平均掉了。
6. **可救回的空间很大**：最终都错的 1023 个里，969 个两边预测相同（锁死），但有 566 个在训练中曾被某一方判对过，
   只有 457 个从头到尾都错。

**证明了什么**
- 停滞 = 双向蒸馏收敛到共识不动点；破坏互补信息的主要是「老师 → 学生」这一方向：学生在自己判对、老师判错的样本上，被对齐损失拉向老师的错误标签。
- 「学生 → 老师」方向（MGVA）是净正的，冻结老师有害。
- 加大老师容量、把学生概率平均进目标，都不能打破不动点。

**没有证明的**
- 1 个种子、1 个任务。
- 还不知道能否不用标签，在分歧样本上分辨「学生对」和「老师对」。这是下一步的关键（可以先用 samples.npz 离线检验）。

## 补充：分歧裁决分析（`scripts/run_arbitration.sh` → `tools/arbitration_analysis.py`，不训练）

在每次评估的分歧样本（学生预测 ≠ 老师预测）上，检验无标签信号能否分辨谁对。底座 both_samples，第 612 步之后加权：

| 规则 | acc | 保学生 | 从老师学 |
|---|---|---|---|
| always_student | **37.4** | 100 | 0 |
| always_teacher | 19.9 | 0 | 100 |
| ent_raw / ent_rank | 33.2 / 32.5 | 63.0 / 57.1 | 48.7 / 56.3 |
| stab / src / zs | 32.1 / 27.6 / 34.5 | 51.7 / 29.8 / 70.4 | 64.3 / 82.5 / 41.0 |
| vote3 | 31.6 | 45.5 | 73.5 |

- 熵、预测稳定性、源模型 / 零样本投票都只比随机好一点（保学生 + 从老师学 = 111–119，随机为 100），没有一条超过「总听学生」。其余 3 组结论相同。
- 可用的是不对称：第 612 步之后分歧样本上学生判对的次数约为老师的 2 倍；早期相反（第 136 步老师 34.2、学生 23.7），交叉点约在第 204 步。
- 下一步：`--align_agree_after`，后期只在师生一致的样本上做对齐（`scripts/run_collapse.sh` 第 2 轮：both_agree010 / both_agree025）。
  上限是并集峰值（约 79.3）；969 个锁死的共识错误靠裁决碰不到。

## 补充：交叉点检测（`scripts/run_crossover.sh` → `tools/crossover_analysis.py`，不训练）

检验不用标签能否判断「当前阶段学生和老师谁更准」（整体，不是逐样本）。注意 freezeT020 / selfknn025 在触发点之前和底座逐点相同，
早期实际只有两条独立轨迹（底座、adapter12）。

真实交叉点：底座 / freezeT020 / selfknn025 第 204 步，adapter12 第 340 步（进度 7.5% / 12.5%）。
学生 − 老师的差在第 408 步左右最大（底座 +3.6），之后随一致率升到 97% 缩小到 +0.6。

| 估计器 | 表现 | 实际测到的是什么 |
|---|---|---|
| ref_src | 从第 68 步起一直为正 | 学生由源模型初始化，等于「总说学生强」 |
| ref_zs | 一直为负 | 老师由零样本 CLIP 初始化，等于「总说老师强」 |
| ref_geo | 在 0 附近，符号无规律 | 两个偏差没有抵消成有用信号 |
| ent_rank | 前 10 次评估符号一致 90%（底座），第 136 步早报一次；adapter12 早报到第 136 步（真实 340）；后期分歧样本少，符号乱 | 唯一和交叉点有关的信号，但很弱（±0.01） |
| concede | 几乎一直为负：学生让步多于老师，学生更准时也一样 | 蒸馏的流向，不是准确率；定量印证「学生吸收老师错误」 |
| stable | 几乎一直为负：学生翻转多 | 两边学习率不同，不是准确率 |

结论：没有可靠的在线检测器；交叉点在两条轨迹上落在进度 7.5%–12.5%，用固定切换点即可（agree010 = 第 272 步正好在这个范围）。
另一个发现：对齐权重 `min(1, 2 × 进度)` 在学生已经更准的阶段（第 204 步后）才从 0.15 加到 1，和「谁更准」正好相反。
