# 实验 0 重做（类名修复后）：OT 静态诊断（2026-10-15）

## 概要

**为什么做**
原实验 0（`../2026_10_14_diag/`）是在类名错位（第 58–63 类 CLIP 提示词配错）时做的。修复后 CLIP 起点更高，
需要确认 H1 / H2 / H3 的结论是否还成立，并为快速诊断和 μ_p 估计诊断重新生成快照。

**做了什么**
`bash scripts/run_diag.sh`：Ar→Cl、Pr→Re 训练到 1/2，在 0 / 0.25 / 0.5 保存快照（`process/DiagFix/`），
用 `tools/diag_ot.py` 逐批测 H1 / H2 / H3。设置同原实验 0（批 64，种子 0 1 2，每阶段 204 批）。

**结论**

| | CLIP | 计划 argmax | 模型 | H1 缺席质量（实际 μ） | H2 尺度翻倍最大变化 | H3 Cv/Cm |
|---|---|---|---|---|---|---|
| Ar→Cl p000 / p025 / p050 | 63.6 / 72.9 / 73.6 | 61.9 / 72.1 / 73.5 | 41.9 / 73.0 / 74.3 | 19.7 / 14.4 / 12.8% | 4.4 / 4.3 / 1.4 pp | 1.46 / 1.17 / 1.07 |

- 计划 argmax ≈ CLIP argmax，和修复前一样；模型在 p025 后追上 CLIP。
- H1：缺席质量随 CLIP 变准而下降，Pr→Re p050 降到 4.5%（重加权后 5.2%）。H2：仍主要通过 μ_p 起作用。
- H3：本表 p025 / p050 的值有列边际偏差（同原实验 0），以快速诊断里的修正值为准。

**证明了什么**
- 类名修复后，实验 0 的所有定性结论不变，只是 CLIP 和计划的准确率整体上升 6–9 个百分点。
