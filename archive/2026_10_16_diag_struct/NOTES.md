# 目标域结构诊断：用学生特征空间的结构修正 CLIP 伪标签（2026-10-16）

## 概要

**为什么做**
OT 这条线已经收尾：无论批内还是全域、用哪种无标签边际，OT 计划都超不过 CLIP，学生始终只在学 CLIP 逐个样本的判断。
SFDA 的研究对象是适配本身，不能靠改 CLIP。CLIP 没有、学生模型有的信息是「目标域的数据结构」——
适配后的特征空间里同类样本聚在一起（SHOT / NRC / AaD 的依据）。所以测：用学生特征空间的结构修正 CLIP 伪标签，能否超过 CLIP。

**做了什么**
`bash scripts/run_diag_struct.sh` → `tools/diag_struct.py`，用 `runs/DiagFix/` 的 6 个快照（Ar→Cl、Pr→Re × 0 / 0.25 / 0.5），
全数据集一次前向（BN eval），CLIP 不改动。测：[1] CLIP 与模型的互补性；[2] 学生特征空间的近邻投票（k = 5 / 10 / 20）；
[3] SHOT 式原型修正；[4] 代码里算出但未使用的 gamma2。参考：在 CLIP 图像特征空间做同样的投票。

**结论**（±CLIP，百分点；k = 10）

| | p000 | p025 | p050 |
|---|---|---|---|
| knn_clip_s：(自身 CLIP + 近邻 CLIP) / 2，学生特征空间 | Ar→Cl +3.32 / Pr→Re +1.61 | +2.15 / +0.64 | +1.15 / +0.21 |
| ref_knn_clipfeat：同样的投票，CLIP 特征空间 | −1.44 / −3.33 | −2.04 / −2.43 | −0.64 / −2.34 |
| knn_clip：只用近邻（不含自身） | −4.79 / −7.16 | +1.49 / +0.37 | +1.81 / +0.32 |
| knn_model：模型自平滑（NRC 式） | −14.18 / −11.80 | +1.65 / +0.21 | +2.18 / +0.30 |
| proto_clip_it0：原型修正 | −2.91 / −5.07 | +2.34 / +0.00 | +1.28 / +0.02 |
| gamma2 | −17.70 / −16.72 | −0.06 / −0.23 | −0.35 / −0.26 |

- knn_clip_s 在 6 个快照上全部为正，纠正远多于改坏（Ar→Cl p000 242 / 97，p025 146 / 52，p050 78 / 28）；k = 5 / 10 / 20 差别 < 0.5。
- CLIP 自己的特征空间做同样的投票全部为负：有用的结构来自学生，不来自 CLIP。
- 即使在 p000（源模型准确率 47.5%），学生的特征结构也能把 CLIP 提高 3.3 个百分点。
- 互补性：后期两边判断高度一致（Ar→Cl p050 一致率 94%，一致时准确率 77%，两边都错 1048 个、意见不同只有 159 个），
  瓶颈是共享的错误，组合老师和学生的上限只有 76%；结构信息仍能纠正共享错误。
- 不含自身的近邻投票、原型修正、模型自平滑早期都变差，中后期转正；gamma2 全部为负。

**证明了什么**
- 找到了第一个在所有阶段都超过 CLIP 的、属于适配环节的信号：学生特征空间的近邻结构。
- 这个信号是 CLIP 自身没有的（CLIP 特征空间的同样操作为负），符合 SFDA「利用目标域结构」的研究方向。

- 已整理为论点库第 1 条（`../ARGUMENTS.md`）：未经适配的源模型，其特征结构已能纠正 CLIP（p000：Ar→Cl +3.32，Pr→Re +1.61）。

**没有证明的**
- 静态测量；接进训练后能否累积成最终准确率的提升，需要完整训练验证（计划：main.py 加 `--knn_k`，ot / clip_soft × 3 个难任务）。
- 训练中用的是记忆库里的 CLIP 概率和随训练更新的特征库，和这里的「当前 CLIP + 当前特征」略有差别。
