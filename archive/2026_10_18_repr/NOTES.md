# 表示诊断：停滞时学生的表示有没有被同化（2026-10-18）

## 概要

**为什么做**
共识塌缩实验（`2026_10_17_collapse`）说明停滞 = 师生收敛到不动点，「谁对谁错」的裁决和保护类方法上限只是并集峰值（79.3），
突破不了老师。要越过老师，必须有比两者都好的信息来源。旧结论 19 显示瓶颈特征的簇纯度 82.5% 高于并集，
但 k-means 纯度依赖 K 和簇形状，且只测到 p050。这里换成不需要拆分的指标，比较不同层，并测到训练结束。

**做了什么**
`scripts/run_repr.sh`：训练一次 ot_knn10_both（Ar→Cl，seed 42，不开 --log_dynamics），在进度 0 / 0.25 / 0.5 / 0.75 / 1.0 存快照；
`tools/diag_repr.py` 对每个快照、4 个空间（layer3 1024 维 / 骨干 pool2048 / 瓶颈 256 维 / CLIP 512 维）算有效秩、
5 折 CV 线性探针（用标签）、近邻标签准确率（普通 / 互近邻 / CSLS，k = 10）、无标签近邻信号。
一致性：最后 5 次评估均值 75.98，和 ot_knn10_both 逐点相同；耗时 35:19（不开诊断记录）。

**结论**

| | p000 | p025 | p050 | p075 | p100 |
|---|---|---|---|---|---|
| 学生 | 47.51 | 76.11 | 75.97 | 76.01 | 76.06 |
| 老师 | 63.64 | 73.81 | 74.68 | 75.37 | 75.40 |
| 并集 | 72.97 | 79.08 | 77.27 | 76.66 | 76.54 |
| 锁死 | 220 | 645 | 854 | 958 | 970 |
| 探针 pool2048 | 79.68 | 83.96 | 84.83 | 85.29 | **85.02** |
| 探针 bottleneck | 75.21 | 84.01 | 84.35 | 84.49 | 84.26 |
| 探针 layer3 | 78.53 | 79.54 | 79.73 | 80.25 | 80.25 |
| 有效秩 pool2048 / 90% 维数 | 1166 / 440 | 1195 / 462 | 1190 / 463 | 1191 / 469 | 1190 / 460 |
| 有效秩 bottleneck / 90% 维数 | 210 / 132 | 176 / 72 | 163 / 54 | 160 / 53 | 157 / 51 |
| 互近邻标签 bottleneck（全域 / 锁死） | 72.6 / 44.1 | 83.1 / 46.7 | 83.5 / 45.3 | 84.0 / 45.4 | 83.9 / 45.7 |
| 普通近邻标签 bottleneck（全域 / 锁死） | 69.5 / 34.6 | 80.8 / 30.7 | 80.9 / 24.6 | 81.1 / 23.5 | 80.8 / 23.3 |

1. **表示没有被同化，停滞在分类器。** 骨干特征的线性探针到训练结束一直上升到 85.0，比学生高 9 个点，
   高于并集（76.5）、COSMO（76.4）和导师的 81。停滞的不是表示，是「从表示到类别」这一步。
2. **骨干不塌缩，瓶颈塌缩。** pool2048 有效秩不变（1166 → 1190）；瓶颈 210 → 157，90% 方差维数 132 → 51。
   瓶颈的全局探针仍有 84，但在学生判错的样本附近局部结构被拉坏：普通近邻标签在锁死样本上 34.6 → 23.3，
   pool2048 同期保持约 36。骨干学习率是瓶颈的 0.1 倍，和这一点一致。
3. **锁死样本有一半线性可分。** 970 个锁死样本上，pool2048 探针约 52%、layer3 约 57%：真实标签的信息在表示里，
   只是没有无标签的方式取出来。
4. **互近邻明显好于普通 kNN。** 瓶颈互近邻标签准确率在锁死样本上 45.7 vs 23.3，全域 +3；覆盖率 86–96%。
   CSLS 介于两者之间。
5. **现有的无标签近邻信号都用尽了。** 后期 knn_s / mknn_s / knn_t 在各层都只在学生 ±0.8 之间（最好 pool2048 knn_s p050 +0.82）；
   main.py 现在的 knn 平滑（bottleneck knn_t）p100 为 −0.39。近邻的预测本身就是共识，平均不出新信息。

**证明了什么**
- 超出老师的信息存在，且一直存在：线性可分的上限约 85，主要在骨干 2048 维特征里。
- 瓶颈层随训练塌缩（有效维数减半以上），学生判错样本附近的局部结构被同化。
- 基于「近邻当前预测」的平滑类方法在后期没有提升空间。

**没有证明的**
- 1 个种子、1 个任务。探针用了真实标签（权重衰减也在标签上选），是上限，不是方法。
- 不知道不用标签能拿回多少：下一步 `scripts/run_head.sh`（`tools/diag_head.py`），在冻结特征上用学生 / 老师 / 一致样本 /
  高置信样本作标签重拟合线性头。
- 用户贴回的汇总在 mknn_t 表处截断（mknn_t 结果缺失）。

## 补充：无标签重拟合分类头（`scripts/run_head.sh` → `tools/diag_head.py`，不训练网络）

在冻结特征上用无标签来源作标签重拟合线性头（全部样本直推，标签只用于评估），wd = 1e-3 / 1e-2 / 1e-1：

| 快照 | 学生 | 最好的一组（相对学生） | 高置信头（agree_conf，pool2048）在锁死样本上 | 真实标签探针在锁死样本上 |
|---|---|---|---|---|
| p000 | 47.51 | pool2048 soft_avg 66.87（+19.4，比 CLIP 63.64 高 3.2） | 5.0 | 55.0 |
| p025 | 76.11 | pool2048 soft_avg 76.59（+0.48） | 9.0 | 51.8 |
| p050 | 75.97 | bottleneck agree_conf / conf50 76.52（+0.55） | 8.1 | 52.3 |
| p075 | 76.01 | bottleneck agree_conf 76.38（+0.37） | 8.7 | 53.7 |
| p100 | 76.06 | bottleneck agree_conf 76.31（+0.25） | 7.1 | 51.9 |

1. **p025 之后，所有无标签目标都回到学生 ±0.6**，与层、权重衰减无关。p000 时重拟合有用（等价于结构平滑），之后没有。
2. **高置信样本的标签很干净（约 91%），但学出来的边界仍把锁死样本划错**：只用一半高置信样本训练，锁死样本上只对 7–9%；
   真实标签探针在同样的样本上对约 52%。纠正锁死错误需要的信息就在这些难样本自己的标签里，
   干净样本决定的边界不包含它 —— 锁死错误是系统性的，不是噪声。
3. 所以「表示里有 85」不能靠换伪标签来源拿到：凡是由当前师生预测导出的目标，上限都约等于学生（76–76.6）。

**证明了什么**：表示 → 类别这一步的缺口（9 个点）无法用学生 / 老师 / 一致 / 高置信标签重拟合补上；锁死错误位于干净样本边界的错误一侧。
**没有证明的**：锁死错误的具体形状（集中在少数类对？真实类是否常排第 2？）—— 下一步 `scripts/run_locked.sh`（`tools/diag_locked.py`）。

## 补充：锁死错误结构（`scripts/run_locked.sh` → `tools/diag_locked.py`，不训练）

| | p025 | p050 | p100 |
|---|---|---|---|
| 锁死样本 / 类对数 | 645 / 267 | 854 / 342 | 970 / 381 |
| 前 10 个类对占比 / 覆盖 50% 需要的类对数 | 26.2 / 39 | 21.0 / 50 | 18.5 / 57 |
| 反向也混淆的占比 | 41.1 | 35.1 | 36.1 |
| 真实类在学生概率中 第 2 / 前 3 / 前 5 | 48.5 / 63.6 / 75.3 | 44.1 / 61.5 / 74.8 | 46.7 / 60.1 / 73.1 |
| 子簇（K=520）锁死占多数的簇 / 含锁死 / 其余在混合簇 | 50 / 201 / 444 | 80 / 347 / 507 | 118 / 508 / 462 |

1. **分散，不能逐个类对修**：p100 有 381 个类对，前 10 个只占 18.5%，越到后期越分散（锁死在扩散）。
2. **但大多是单向吞并，吸收方是过度预测的类**（p100，预测数 / 真实数）：Calculator 90 / 46（召回 100%）、Lamp_Shade 74 / 40、
   Flipflops 69 / 40、Eraser 69 / 40、Postit_Notes 65 / 41、Mop 61 / 40；被吞并的类预测不足：Telephone 57 / 99、Speaker 53 / 90、
   Screwdriver 49 / 75、Pencil 72 / 99。典型：Telephone → Calculator 30（反向 0）、Desk_Lamp → Lamp_Shade 23（反向 1）。
   互相混淆的只有少数（Monitor ↔ Computer 16 / 16）。
3. **真实类常常就是第 2 名**：学生概率中 47% 排第 2、60% 前 3、73% 前 5。信息在类别排序里，argmax 被过度预测的类拉走。
4. 子簇：一半锁死样本在「锁死占多数」的小簇里（平均 5.6 个样本），这些簇的真实类在簇平均概率中只有 26% 排第 2 —— 簇级命名帮不上。

**推断**：锁死的主因可能是类边际失真（过度预测的类吞并真实类排第 2 的样本），不是 970 个独立的错误。
main.py 的 class_weights（1 / 预测频率）只作用在损失上，不改变分配，μ_p 又来自同样有偏的 CLIP 记忆库。
**下一步**：`scripts/run_marginal.sh`（`tools/diag_marginal.py`）—— 全数据集按不同类边际重新分配，真实边际作上界，判断边际是不是关键杠杆。

## 补充：类边际纠正（`scripts/run_marginal.sh` → `tools/diag_marginal.py`，不训练）

全数据集 Sinkhorn，代价 −log P，按给定类边际重新分配（格内：相对学生；纠正的锁死 / 改坏的学生对）：

| 概率 / 边际 | p025 | p050 | p100 |
|---|---|---|---|
| 学生 / 真实边际（上界，ε = 1） | +2.36 90/77 | +2.50 124/66 | +2.54 140/44 |
| 平均 / 真实边际（上界，ε = 1） | +3.02 85/82 | +2.68 122/70 | +2.36 134/48 |
| 学生 / 预测计数 · 平均概率 | ≈ 0 | ≈ 0 | ≈ 0 |
| 学生 / 平方根收缩（ε = 1） | −0.92 | −0.92 | −0.92 |
| 学生 / 均匀（ε = 1） | −2.29 | −2.20 | −1.92 |

与真实边际的 L1（p100，学生）：预测 0.217、平均概率 0.209、平方根收缩 0.259、均匀 0.327（Clipart 每类 39–99 个样本）。

1. **边际是真的杠杆，但不是主因**：真实边际上界只有 +2.4 ~ +3.0，纠正 140 / 970 个锁死样本（14%）。
2. **无标签估计全部不如直接用预测**：任何向均匀收缩的估计都更差（Clipart 本身不平衡），预测边际已经是最接近真实的无标签估计。
   与旧结论 14（μ_p 估计器超不过 CLIP）一致。
3. 锁死错误的主体（约 85%）是逐样本的系统性错误，不是边际失真。

## 阶段性结论（三个离线诊断合起来）

表示里有约 9 个点的信息（探针 85），但**所有从当前师生预测出发的无标签加工都拿不到**：近邻平滑（±0.8）、重拟合分类头（±0.6）、
类边际重分配（≤ 0，上界 +2.5）。锁死样本从 p000 的 220 个增长到 p025 的 645 个、p100 的 970 个，大部分是训练过程中产生的。
下一步不再在后期加工预测，而是在源头少继承：`scripts/run_weight.sh`（`--align_weight const / cap`，对齐权重曲线）。
