# Ar→Pr 上的两个改动：类均衡推向 CLIP 估计分布 / 可学习类原型（2026-10-20，`scripts/run_ab.sh`）

## 概要

**为什么做**
Ar→Pr 代表 CLIP 强（零样本 87）、准确率 90 上下的任务。两个改动分别针对：固定的均衡力度（sqrt 在 Art +1.2 / Pr −1.5）、
老师固定文本原型分类头（H1：学生缺口继承自它）。

**做了什么**
cap02 底座，Ar→Pr，seed 42：`--clsw_mode prior`（权重 = CLIP 零样本平均概率 μ̂ / 学生预测频率，量级匹配）；
`--t_proto --t_proto_reg 1`（类原型可学习，文本初始化，拉向初始文本）。先检查 μ̂ 的前提。

**结论**

μ̂ 前提检查（训练前快照）：

| 目标 | 真实 最多/最少 | μ̂ 最多/最少 | L1：μ̂ | L1：零样本计数 | L1：均匀 |
|---|---|---|---|---|---|
| Clipart | 2.5 | 18.8 | 0.380 | 0.425 | 0.327 |
| Art | 6.6 | 9.6 | 0.215 | 0.206 | 0.413 |
| Product | 2.6 | 11.0 | 0.164 | 0.137 | 0.272 |
| Real World | 4.3 | 8.3 | 0.137 | 0.115 | 0.184 |

| 组 | Ar→Pr | 相对 cap02 |
|---|---|---|
| cap02 | 91.91 | - |
| prior | 90.59 | −1.33 |
| proto | 91.66 | −0.25 |
| 参考：tstrong / sqrt | 91.63 / 90.39 | −0.29 / −1.52 |
| COSMO | 92.6 | - |

1. **两个都无效**。proto 与 tstrong 一样在噪声内；prior 与 sqrt 一样 −1.3 ~ −1.5。
2. **μ̂ 的 L1 更小但形状错**：μ̂ 最多 / 最少 = 8 ~ 19 倍，真实只有 2.5 ~ 6.6 倍 —— CLIP 零样本严重偏向少数类。
   推向 μ̂ 等于接受 CLIP 的类偏置。在 Product（真实近乎均衡）上，1/频率推向均匀的作用其实是抵消 CLIP 的类偏置，
   所以任何减弱均衡的做法（sqrt、prior）都掉约 1.4。Art 真实就不均衡，推向均匀才会过头。
3. **Ar→Pr 被锁在约 92**：到目前为止 Ar→Pr 上的 13 个改动全部在 [−2.2, +0.21] 内（最好 headlr 92.13），
   cap02 本身相对 ramp 也只 +0.21。师生一致率高、两边共享同样的系统性错误，现有框架内没有一个信号能区分它们。

**证明了什么**
- 均衡项在 CLIP 强、类别均衡的目标上承担「去除 CLIP 类偏置」的作用，不能减弱；μ̂ 不能作为目标分布。
- 在训练中让老师原型可学习，学到的仍是师生共识。

**没有证明的**
- 单种子；Ar→Pr 种子方差未测（COSMO 92.6 是 3 种子均值）。
